# arduino-control-panel
Arduino Nano + энкодер для управления яркостью, громкостью и музыкой на Windows. Python-приложение поддерживает 2 режима, настраиваемые действия энкодера, запуск .exe, управление Spotify/Yandex Music, автоматический поиск COM-порта и работу в системном трее.
